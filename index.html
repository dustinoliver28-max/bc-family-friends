Download for Android

Android 9 or newer · about 50 MB · no iPhone version

How to install

  1. Tap Download for Android, then open the file when it finishes.
  2. Your phone will say it can't install apps from this source. Tap Settings, turn on Allow from this source, then go back and tap Install.
  3. Open BC Vault, pick a wallpaper, then tap Set wallpaper.

If Play Protect shows a warning, tap More details → Install anyway. It warns about every app that isn't from the Play Store.
